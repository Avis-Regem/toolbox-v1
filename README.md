A simple Python command-line toolbox with useful utilities, fun games, a calculator, a todo list, and a text editor launcher.
possible bugs still remain, if you find any please alert me at my discord: @krios_kalashnikov
txteditor.py is for the texteditor command.
this is modelled after telehack, which you can access by enabling telnet and typing telnet telehack.com in your command prompt or simply visiting telehack.com on your web browser.
